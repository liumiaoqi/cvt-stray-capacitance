# Agent Note: 分压比的频率无关性，以及 CVT 的频率敏感性来自何处

Status: implemented

## Problem

CVT 误差的常见讲法把「频率」列为误差来源，理由是「两臂损耗角不同，频率变化打破平衡」。

这个推理经不起推导。并联模型 `Y = ωC(tanδ + j)` 与串联模型 `Z = (tanδ − j)/(ωC)` 中，`ω` 都是公因子，在 `Y₁/(Y₁+Y₂)` 或 `Z₁/(Z₁+Z₂)` 里相消。数值核对：50 Hz 与 50.2 Hz 的复比之差为 0，两臂损耗角取不同值也一样。

照抄这个讲法，等于把一个不成立的机制写进报告。

## Decision

报告第 4 章的「频率」一项按如下方式陈述：

1. **分压器本身对频率不敏感**——即使两臂损耗角不同；
2. CVT 的频率敏感性来自**补偿电抗器**：它按额定频率与分压器电容配谐，频率偏离即失谐，残抗约 `2δX_L`（`δ` 为相对频偏）。

复算见 `derivations.wls` 第 B 段。

## Alternatives considered

**为什么不保留「损耗角不同则频率影响」的说法？**
因为它算错了。即使结论（频率确实影响 CVT 误差）成立，**机制归错也会让后续推论跑偏**——例如据此去做「两臂损耗角匹配」以改善频率特性，投入方向就错了。

**为什么不干脆删掉「频率」这一项？**
因为 CVT 确实有频率敏感性，只是不落在分压器上。删掉会丢掉一个真实的误差源。

**为什么只给残抗公式，不给完整的频率误差曲线？**
完整曲线需要补偿电抗器的电感值、品质因数与中间变压器参数，本报告没有这些数据。`2δX_L` 只依赖谐振条件本身，不需要额外参数。

## Consequences

报告不再声称「损耗角差异导致频率敏感性」。按常见讲法核对的读者会发现与报告不一致——**这是有意的**，本仓脚本可复现该结论。

失谐引起的误差量级未给出（缺电抗器与中间变压器参数），因此这一项在报告中仍只作定性列举，未进入定量核算。
