### 1. 比值差随高压引线夹角的变化（报告图 4）

模型：`C_spur = 10 pF · cos θ` 并入高压臂；`C₁ = 1 nF`、`C₂ = 1 μF`；额定变比 `Kₙ = K = 1001`。

| θ (°) | 0 | 15 | 30 | 45 | 60 | 75 | 90 |
|---|---|---|---|---|---|---|---|
| 比值差 ε (%) | 0.99899 | 0.96495 | 0.86515 | 0.70640 | 0.49950 | 0.25856 | 0 |

### 2. 两臂灵敏度的不对称

```
|∂K/∂C₁| / |∂K/∂C₂| = C₂/C₁ = K − 1
```

本参数下 = **1000**（数值核对 1000.000）。

### 3. 同样的 10 pF 加在不同位置

| 加在 | 比值差 |
|---|---|
| 高压臂（C₁ = 1 nF） | **+0.999%** |
| 低压臂（C₂ = 1 μF） | **−0.001%** |

相差约 `K − 1` 倍。这是「屏蔽优先施于高压侧」的定量依据。

### 4. 与准确级限值比较

GB/T 20840.5—2013 表 501：0.2 级 ±0.2%、0.5 级 ±0.5%、1.0 级 ±1.0%。

最大比值差 0.999% = **0.2 级限值的 5.0 倍**、0.5 级的 2.0 倍。

### 5. 温度：关键在于两臂是否同介质

```
K(T) = 1 + (C₂/C₁)·(1 + β₂ΔT)/(1 + β₁ΔT)
一阶： ΔK/K ≈ ((K−1)/K)·(β₂ − β₁)·ΔT
```

- **β₁ = β₂（同介质）→ 分压比精确不变**（数值核对 0）
- β₁ = 2×10⁻⁴、β₂ = 1×10⁻⁴、ΔT = 50 K → ΔK/K = **−0.495%**，即比值差 +0.5%

**⇒ 温度误差由两臂温度系数之**差**决定，不是由系数本身决定。** 上述量级已远超 0.2 级限值。

### 6. 频率：分压器不敏感，敏感性在电抗器

**这条纠正了报告初稿的一处错误。**

对并联模型 `Y = ωC(tanδ + j)` 或串联模型 `Z = (tanδ − j)/(ωC)`，ω 都是公因子：

```
U₂/U₁ = C₁(tanδ₁+j) / [C₁(tanδ₁+j) + C₂(tanδ₂+j)]      ← 与频率无关
```

数值核对：50 Hz 与 50.2 Hz 的复比之差的绝对值 = **0**（即使两臂 tanδ 不同）。

**⇒ 纯电容分压器的分压比与频率无关，损耗角不同也不改变这一点。**

CVT 的频率敏感性来自**补偿电抗器**：额定频率下 `ω₀L = 1/(ω₀C_Σ)`，偏离 δ 时残抗

```
ΔX / X₀ = (1+δ) − 1/(1+δ) ≈ 2δ
```

50 → 50.2 Hz（δ = 0.4%）时残抗约为 `X₀` 的 **0.798%**。失谐由此产生，与两臂损耗角无关。

### 7. 能量法求电容（验证文献方法的基础）

liugang2020 用有限元算出空间电场能量作为方程右端项，再解出感应系数矩阵。其前提是 `W = CV²/2` 这一步。

以同轴结构对拍：

| | 值 |
|---|---|
| 能量积分得 `C` 与解析值 `2πε/ln(b/a)` 之比 | **1.00000000** |

### 8. 感应系数矩阵与电容矩阵互逆

多导体系统 `Q = C·V`、`V = α·Q` ⇒ `C = α⁻¹`。三导体例子核对 `α·C = I`，残差 0。

## 三、两处口径说明

### 额定变比与设计变比

比值差以**额定变比** `Kₙ = U₁ₙ/U₂ₙ` 为基准：

```
ε = (Kₙ·U₂ − U₁)/U₁ × 100%
```

而 `K = (C₁+C₂)/C₁` 是由电容值算出的**设计变比**。两者不必相等：`Kₙ` 是规格值，`K` 由实际电容决定。

本仓取 `Kₙ = K`，故 θ = 90°（杂散电容为零）处 ε 精确为 0。取其他 `Kₙ` 只会使整条曲线平移一个常量，不影响斜率与灵敏度结论。

### 只算静态

本仓只复算**稳态比值差**，不涉及暂态响应与铁磁谐振。这两项在报告中作为误差来源列出，但未做定量分析——没有相应数据，写不出可核对的数。

温度系数 `β` 与损耗角 `tanδ` 取的是**量级典型值，不是实测值**，因此第 5、6 节给的是**量级判断**，不是该型号的具体误差。
