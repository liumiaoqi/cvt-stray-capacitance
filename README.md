## 一、复算结果一览

运行 `stray_capacitance.wls` 得到，12 项断言全部通过。

### 1. 比值差随高压引线夹角的变化（报告图 4）

模型：杂散电容 `C_spur = 10 pF · cos θ` 并入高压臂；`C₁ = 1 nF`、`C₂ = 1 μF`；额定变比取 `Kₙ = K = 1001`。

| θ (°) | 0 | 15 | 30 | 45 | 60 | 75 | 90 |
|---|---|---|---|---|---|---|---|
| 比值差 ε (%) | 0.99899 | 0.96495 | 0.86515 | 0.70640 | 0.49950 | 0.25856 | 0 |

> θ = 90° 处归零，与「引线与本体轴线垂直时杂散耦合消失」的物理预期一致。

### 2. 两臂灵敏度的不对称

分压比 `K = 1 + C₂/C₁`，对两臂电容的灵敏度之比为

```
|∂K/∂C₁| / |∂K/∂C₂| = C₂/C₁ = K − 1
```

本参数下 = **1000**（数值核对 1000.000）。

### 3. 同样的 10 pF 加在不同位置

| 加在 | 比值差 |
|---|---|
| 高压臂（C₁ = 1 nF） | **+0.999%** |
| 低压臂（C₂ = 1 μF） | **−0.001%** |

**相差约 1000 倍**，即 `K − 1` 倍。这是「屏蔽必须优先施于高压侧」的定量依据——不只是那一侧耦合对象更多，同样大小的耦合造成的误差本身就被放大三个数量级。

### 4. 与准确级限值的比较

GB/T 20840.5—2013 表 501（测量用电容式电压互感器）：

| 准确级 | 比值差限值 | 相位差限值 |
|---|---|---|
| 0.2 | ±0.2% | ±10′ |
| 0.5 | ±0.5% | ±20′ |
| 1.0 | ±1.0% | ±40′ |

最大比值差 0.999% 相当于 **0.2 级限值的 5.0 倍**、0.5 级的 2.0 倍。

> 该限值是标准给定值，本仓只做倍数核对，不重新推导。

## 二、怎么跑

```
wolframscript -file stray_capacitance.wls
```

需要 Wolfram Engine 12.0+（开发者许可免费）。脚本逐条对照断言打印 `OK / FAIL`，任一条超差即以**退出码 1** 结束。

输入参数在脚本开头（`c1`、`c2`、`dcMax`），改这三个值即可复算换参数后的情形。

## 三、两处口径说明

### 额定变比与设计变比

报告按 GB/T 20840.5 的定义，比值差以**额定变比** `Kₙ = U₁ₙ/U₂ₙ` 为基准：

```
ε = (Kₙ·U₂ − U₁)/U₁ × 100%
```

而 `K = (C₁+C₂)/C₁` 是由电容值算出的**设计变比**。两者不必相等：`Kₙ` 是规格值，`K` 由实际电容决定。

本仓取 `Kₙ = K`，因此 θ = 90°（杂散电容为零）处 ε 精确为 0。若取其他 `Kₙ`，整条曲线会平移一个常量——这不影响曲线的形状，也不影响斜率与灵敏度结论。

### 为什么只算静态

本仓只复算**稳态比值差**，不涉及暂态响应、铁磁谐振与补偿电抗器失谐。这三项在报告中作为误差来源列出，但未做定量分析——没有相应的实测或仿真数据，写不出可核对的数。
